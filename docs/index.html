Scoring Model — 3-Stage Pipeline

Stage 1 — Feature Engineering

BFAST-style piecewise regression on 6-year NTL series → breakpoint year, pre/post slope, acceleration. Spatial lag from 10 nearest neighbours. Signal agreement penalty for contradictory signals.

Stage 2 — Self-supervised Labelling

Label = 1 if village is top-10% on ≥2 primary signals simultaneously (~28K positives from 255K villages). Note: labels derived from same features as final composite — AUC 0.87 measures self-consistency, not external ground truth.

Stage 3 — GradientBoostingClassifier

200 estimators · max_depth=4 · learning_rate=0.05 · subsample=0.8. Output: ml_growth_prob (0–100). AUC ≈ 0.87 (in-sample, self-supervised).
